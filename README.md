# 게임 YouTube 데이터 보드

자동차를 운전해 명조, 이환, 젠레스 존 제로 구역을 방문하고, 각 게임의 한국어 YouTube 일반 영상과 쇼츠 공개 지표를 탐색하는 정적 데이터 사이트입니다.

- `/` — 레이싱·슬라럼·점프와 세 게임 데이터 구역을 갖춘 3D 드라이빙 파크
- `https://krksw96.github.io/wuthering-waves-vod-dashboard/dashboard.html?game=wuthering-waves` — 명조 데이터 보드
- `/dashboard.html?game=neverness-to-everness` — 이환 데이터 보드
- `/dashboard.html?game=zenless-zone-zero` — 젠레스 존 제로 데이터 보드

- 게임별 데이터 보드 전환
- 영상 및 크리에이터 검색
- 날짜와 콘텐츠 주제 필터
- 조회수, 좋아요, 댓글, 최신순 정렬
- 모바일 카드 레이아웃
- 필터 결과 CSV 다운로드
- 게임별 바로가기 카드와 3D 파크 미리보기
- 탐험 후 로비 복귀, 홈·데이터 보드 간 언어 설정 유지
- 작은 화면과 키보드 탐색을 지원하는 반응형 인터페이스

## 디자인 구성

홈과 데이터 보드는 차콜 배경, 라임색 브랜드 포인트와 게임별 구역 색상을 공유합니다.

- `styles/design-system.css` — 공통 색상, 글꼴, 포커스와 모션 설정
- `styles/lobby.css` — 홈, 게임 선택 카드와 드라이빙 HUD
- `styles/driving.css` — 주행 모드 선택, 기록·체크포인트 HUD와 터치 조작
- `styles/dashboard.css` — 지표, 검색 필터, 영상 목록과 상세 창

3D 파크는 홈에서 정적인 미리보기로 표시하며, 주행을 시작하면 전체 화면으로 전환합니다. 동작 줄이기 설정에서는 장식 애니메이션을 생략합니다.

## 드라이빙 파크

잔디와 나무, 굽이치는 아스팔트 서킷, 오두막과 호수를 배경으로 네 가지 모드를 플레이할 수 있습니다.

- **자유 주행** — 파크를 탐험하고 색상별 데이터 터미널 안에 머물러 대시보드를 엽니다. 동쪽 연결 도로를 따라 오두막 3채, 벤치와 나무 데크가 있는 호숫가를 방문하거나, ‘호숫가로 이동’ 버튼으로 바로 이동할 수 있습니다.
- **레이싱** — 3초 카운트다운 후 출발해 연속 굴곡과 타이트한 코너가 있는 약 771m 서킷을 달립니다. 20개 체크포인트를 순서대로 통과하고 출발선으로 돌아오면 한 바퀴의 시간이 기록됩니다.
- **슬라럼** — 18m 간격으로 놓인 고깔 7개를 지그재그로 통과합니다. 14m 폭의 도로에서 후진 없이 다음 게이트로 이어갈 수 있으며, 고깔마다 최초 충돌 시 2초 페널티가 추가됩니다.
- **점프** — 큰 점프, 연속 점프, 연습 점프 중에서 코스를 선택합니다. 이륙대 4개와 착지대 4개를 갖추었으며, 연속 점프 코스에서는 두 번의 점프를 이어 달릴 수 있습니다. 착지할 때 수평 비거리와 체공 시간을 측정하고, 이후에도 자유롭게 재도전할 수 있습니다.

WASD/방향키로 주행하고, Shift로 부스트, Space로 드리프트, R로 현재 코스를 다시 시작합니다. 주행 중 모드 변경과 재시작 버튼을 사용할 수 있습니다. 모바일에서는 화면의 방향·가속·브레이크·부스트·드리프트 버튼을 사용합니다.

잔디에서는 속도가 줄고, 고깔은 충돌 방향으로 넘어지며, 점프대 경사와 착지에 맞춰 차체가 반응합니다. 부스트를 사용하면 뒤쪽의 푸른 불꽃과 밝은 코어가 속도에 따라 길어집니다. 미니맵에는 호수와 점프대가 표시되며, 강조된 게이트가 다음 체크포인트를 안내합니다. 챌린지 모드 중에는 데이터 터미널로 자동 이동하지 않습니다.

최고 기록은 현재 브라우저에 저장되며 새로고침 후에도 유지됩니다. 변경된 코스의 기록은 `data-drive-records-v2`에 별도로 저장해 이전 코스 기록과 섞이지 않습니다. 탭이 숨겨지면 주행과 타이머가 일시 정지됩니다.

- `scripts/driving-park.mjs` — 코스, 자연 배경, 스폰 위치와 충돌 지형
- `scripts/park-scenery.mjs` — 호수, 오두막, 벤치, 산책로와 호숫가 충돌 지형
- `scripts/driving-car.mjs` — 쿠페 차체, 휠과 주행 효과
- `scripts/driving-surfaces.mjs` — 도로·잔디 판정과 점프대 표면 높이
- `scripts/driving-challenges.mjs` — 체크포인트, 타이머, 페널티와 기록
- `scripts/drive-portal.mjs` — 입력, 차량 물리, 카메라와 UI 연결

주행 관련 검증:

```powershell
npm.cmd test
```

## 데이터 갱신

각 게임 데이터는 서로 덮어쓰지 않도록 독립 파일로 관리합니다.

- `data/wuthering-waves.js`
- `data/neverness-to-everness.js`
- `data/zenless-zone-zero.js`

명조 수집 결과를 갱신한 후 아래 명령을 실행합니다.

```powershell
npm.cmd run sync
```

이환 데이터는 인증된 Feishu 원본 시트에서 다시 생성합니다.

```powershell
npm.cmd run sync-neverness
```

광고 과업 태그는 Feishu `0GfgFb` 탭의 링크(G열, 영상 ID 보조)를 기준으로 모든 데이터 갱신 전에 자동 동기화됩니다.
인증된 KOL 데이터 작업이 공개한 광고 ID 목록을 기본으로 읽으며, `FEISHU_APP_ID`, `FEISHU_APP_SECRET`이 있으면 시트를 직접 읽습니다.

```powershell
npm.cmd run sync-ad-tags
```

## 로컬 실행

```powershell
npm.cmd run serve
```

기본 주소는 `http://127.0.0.1:8091`입니다.

3D 로비에 필요한 Three.js 모듈은 사이트에 함께 포함됩니다. WebGL을 사용할 수 없는 환경에서는 게임별 데이터 보드 바로가기가 표시됩니다.
