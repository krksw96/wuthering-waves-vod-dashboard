# 명조 KOC 콘텐츠 분석

[사이트 열기](https://krksw96.github.io/wuthering-waves-vod-dashboard/koc/)

Lark **명조 KOC DB → 메인 DB (`4z1yjS`)**의 실제 데이터를 분석합니다. 기존 미리보기 데이터와 합치지 않습니다.

## 기능과 집계 기준

- 버전, 최근 1주·1개월·1년·전체 기간·직접 날짜 선택
- 정확한 KOC 선택, 영상 검색, 콘텐츠 주제와 영상 형식 필터
- 같은 필터에 함께 반응하는 누적 조회수·좋아요, 좋아요율, 영상 수, KOC 수
- 업로드일별 성과 차트, 주제별 비교, KOC 순위, CSV 다운로드
- 마지막 원본 지표 갱신과 사이트 동기화 시각을 각각 표시

기간은 **영상 업로드일** 기준입니다. 조회수와 좋아요는 원본에 기록된 최신 누적값이며 기간 중 발생한 증가량이 아닙니다. 좋아요율은 두 지표가 모두 확인된 영상의 합계로 계산합니다. 다중 주제 영상은 주제별 비교에 중복 포함될 수 있으나 전체 지표에는 한 번만 집계됩니다.

최근 일주일은 오늘 포함 7일입니다. 한 달·일 년은 이전 달·이전 해의 같은 날짜 다음 날부터 오늘까지이며 한국 시간과 월말·윤년을 처리합니다. 버전은 원본 B열을 그대로 사용합니다. 주제는 원본 O열의 한국어 표시를 사용하고 중국어 번역을 별도 주제로 세지 않습니다. 빈 주제는 미분류입니다.

## 현재 데이터 연결

원본의 최신 좋아요 H열·조회수 I열을 사용합니다. 정산용 U·V열은 사용하지 않습니다. 크리에이터·게시일 등이 없는 불완전한 행은 제외 건수를 표시합니다. 원본 내용을 수정하지 않습니다.

데이터 수집은 현재 Windows 사용자가 인증한 `lark-cli`로 수행합니다. 인증 토큰을 GitHub나 웹사이트에 복사하지 않습니다. 읽는 도중 원본 revision이 바뀌거나 범위가 잘리면 결과를 반영하지 않습니다.

## 자동 업데이트

Windows 작업 `WutheringWaves-KOC-Lark-Sync`가 **6시간마다 및 사용자 로그인 시** 원본 전체 읽기 → 테스트 → 데이터 파일만 커밋·push를 수행합니다. GitHub Pages가 변경을 배포하고, 열어둔 사이트는 5분마다 게시된 JSON을 다시 확인합니다.

**이 PC가 켜져 있고 사용자가 로그인한 상태에서 갱신됩니다.** PC가 꺼져 있거나 Lark·GitHub 인증이 만료되면 사이트에는 마지막 정상 데이터가 유지됩니다. 작업 중인 코드·스테이징·미게시 사용자 커밋이 있으면 보존을 위해 자동 게시를 중단합니다.

상태는 `koc/tmp/sync-status.json`, 기록은 `koc/tmp/sync.log`에 저장하며 Git에서 제외합니다. GitHub의 `sync-koc-lark.yml`은 별도 앱 인증을 갖춘 클라우드 실행용 대안이며 현재 비활성입니다.

## 로컬 실행과 운영

Node.js 22 이상을 사용하며 추가 npm 패키지는 필요하지 않습니다. 저장소의 `koc/`에서 실행합니다.

```powershell
npm start                    # http://127.0.0.1:8096
npm test                     # 날짜·필터·원본 파싱·게시 보호 검증
npm run sync                 # 현재 Lark 로그인으로 데이터만 갱신
npm run refresh:publish      # 깨끗한 main 저장소에서 갱신하고 게시
```

재설치 시 `scripts/register-local-sync.ps1 -Install`을 사용합니다. 토큰 재인증·원본 열 매핑·클라우드 전환 설명은 [SOURCE_SETUP.md](docs/SOURCE_SETUP.md)에 있습니다.
