# 명조 KOC 콘텐츠 분석

기간, KOC, 콘텐츠 주제와 버전으로 영상의 누적 조회수·좋아요를 함께 살펴보는 한국어 분석 사이트입니다. 설치할 외부 패키지 없이 Node.js 22 이상에서 실행됩니다.

```powershell
npm start
```

로컬 주소는 http://127.0.0.1:8096 입니다.

이 프로젝트는 기존 VOD 사이트 저장소의 `koc/` 폴더에 있습니다. 위 명령은 `koc/`에서 실행합니다. 게시 경로는 https://krksw96.github.io/wuthering-waves-vod-dashboard/koc/ 입니다.

## 현재 연결 상태

**요청한 Lark 원본은 아직 연결되지 않았습니다.** API가 원본 읽기 권한 부족을 반환했고 브라우저 접근도 승인되지 않았습니다. 사이트 상단에 연결 대기 상태를 계속 표시합니다.

현재 `data/koc-data.json`은 기존 공개 명조 VOD 사이트에서 로컬에 저장된 KOC 영상 중 제목에 명조·워더링 웨이브·Wuthering Waves가 포함된 데이터의 **명시적인 미리보기**입니다. 요청한 시트를 읽었다고 표시하지 않습니다. 미리보기 주제는 제목 키워드 분류이며 버전은 임의로 추정하지 않습니다. 기존 스냅샷 날짜를 그대로 유지합니다.

원본: https://ojpvaupdkdbj.jp.larksuite.com/wiki/TjncwLOoOi0Ds2kBpiKjKetSpH4?sheet=4z1yjS

## 분석 기능

- 일주일, 한 달, 일 년, 전체 기간, 직접 날짜 선택
- 정확한 KOC 선택, 제목·KOC 검색, 콘텐츠 주제·영상 형식·버전 복합 필터
- 모든 필터에 연동되는 영상 수, 조회수, 좋아요, 좋아요율, KOC 수
- 업로드일별 성과 차트, 콘텐츠 주제별 비교, KOC 순위
- 페이지형 영상 목록과 CSV 다운로드
- 모바일 레이아웃과 키보드 탐색
- 5분마다 게시된 JSON 재확인 및 수동 새로고침

날짜는 **업로드일 기준**입니다. 지표는 선택 기간에 업로드된 영상들의 최신 누적 수치이며 해당 기간에 새로 발생한 조회수나 좋아요 증가량이 아닙니다. 누락된 지표는 `—`로 구분합니다. 좋아요율은 조회수와 좋아요가 모두 확인된 영상의 합계로 계산합니다. 여러 주제가 있는 영상은 주제별 차트에 중복 포함될 수 있지만 전체 지표에는 한 번만 집계됩니다.

최근 일주일은 오늘을 포함한 7일입니다. 한 달과 일 년은 이전 달·이전 해의 같은 날짜 다음 날부터 오늘까지이며 월 말과 윤년을 처리합니다. 예: 2026-11-14 기준 한 달은 2026-10-15~2026-11-14입니다. 조회 기준 시간대는 한국 시간입니다.

## 원본 연결과 자동 업데이트

[SOURCE_SETUP.md](docs/SOURCE_SETUP.md)에 Lark 읽기 권한, 열 매핑, 최초 검증 및 GitHub Actions 설정 방법을 정리했습니다.

```powershell
npm test
npm run sync
```

동기화는 시트를 읽기만 하며 수정하지 않습니다. API 인증정보는 환경변수·GitHub Secrets에만 둡니다. 동기화가 완전히 성공한 경우에만 공개 JSON을 교체하며, 실패하면 마지막 정상 데이터를 유지합니다.

자동화는 `KOC_LARK_SYNC_ENABLED=true`를 설정하기 전에는 실행되지 않습니다. 현재는 **자동 동기화가 활성화되지 않은 상태**입니다. 활성화 후 6시간마다 원본을 확인하도록 준비되어 있습니다. 프런트엔드의 5분 새로고침은 이미 게시된 데이터만 재확인하므로 Lark 동기화 주기와 다릅니다.

실제 워크플로 파일은 저장소 최상위 `.github/workflows/sync-koc-lark.yml`이며 실행 폴더는 `koc/`입니다.

## 검증

```powershell
npm test
```

윤년·달력 경계, 복합 필터, 비공개와 0의 구분, 좋아요율, 주제 중복 집계, CSV 수식 방지, URL 검증과 원본 파싱을 검증합니다.
